# AI Council: glossary

| Term | Meaning in this package |
|---|---|
| Council | A review organized around distinct analytical roles and a synthesis |
| Seat | One analyst role with an assigned job |
| Mandate | The specific questions and evidence a seat is responsible for |
| Chair | The role that weighs the record and synthesizes the recommendation |
| Simulated perspectives | Sequential roles produced in one model context; earlier text can influence later text |
| Isolated initial calls | Separate first-round contexts that do not include other seats' answers |
| Independence | Here, separation of initial responses; it does not establish statistical independence between models |
| Critique | Examination of specific claims after all initial responses are available |
| Disagreement map | A record of unresolved factual, methodological, or values-based differences |
| Confidence | A reasoned uncertainty label, not a calibrated probability |
| Candidate finding | A concern requiring evidence or validation before it is treated as confirmed |
| Preflight | A local check before model use or a live experiment |
| Fingerprint | A SHA-256 value that detects changes to file contents |
| Held-out case | An example not used to develop or adjust the workflow |
| Baseline | The existing or simpler process used for comparison |
